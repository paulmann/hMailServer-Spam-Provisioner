hMailServer-Spam-Provisioner

A spam folder for every mailbox, in one run

Idempotent PowerShell 7.5 provisioner: creates a [SPAM] IMAP folder and a matching account-level rule for every active hMailServer mailbox, detecting X-hMailServer-Spam or [SPAM] subject tags.

What it does

  • Per-mailbox [SPAM] folder and account-level rule
  • Detects X-hMailServer-Spam header and subject tag
  • Safe to re-run: existing folders are left alone

Built with

PowerShell
